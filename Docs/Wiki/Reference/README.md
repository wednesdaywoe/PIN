## Reading these

**Row counts are not variety.** Firefall generated its gear in level and quality tiers, so the same
weapon appears dozens of times with different numbers. These pages group those rows and print the
spread as `40 to 1200`, which is the progression rather than a range of different things. Where a
page drops rows it says how many and why, at the top.

**Names are three different things.** An English display name comes from
`dblocalization::LocalizedText` and is what a player saw. An internal name is what a designer typed
and is often more honest about intent. A missing name means neither shipped, which usually means the
row was never player-facing. Internal names are evidence, not documentation: template 12115 is
called "David's Magic HMG" and it is in 255 shipping items.

**This is build 1962 and only build 1962.** Firefall was rebuilt at v1.0 and again at v1.6, so a
2013 wiki article describing the same weapon is describing a different weapon. See
[Client Version](../Client-Version.md).

## Regenerating

Point `Tools/SdbDocs/config.json` at a full `clientdb.sd2` and run it:

```
cd Tools/SdbDocs
cp config.example.json config.json    # then edit "input"
dotnet run
```

It has to be the full client database, not one `MinimalSDB prune` produced: the pruned copy drops
`dblocalization::LocalizedText` and every name would come out blank. Output goes to this directory
unless `output` is set.
