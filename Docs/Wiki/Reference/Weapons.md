# Weapons

Generated by `Tools/SdbDocs` from a build-1962 `clientdb.sd2` (db patch prod-1962, built 2016-05-05).

`dbitems::Weapons` holds 6789 rows. 1705 have no English name and are left out;
0 more name a template that does not exist. The rest are level and quality tiers of far
fewer weapons, so rows are grouped by name and template and each column shows the range across the
tiers in that group: **752 player weapons, 192 NPC weapons**.

Every figure is resolved through `SDBUtils.GetDetailedWeaponInfo`, the same call the server makes
when it equips a weapon, so it is the template value with that item's
`dbitems::WeaponTemplateModifiers` row applied as `(base + modifier) * multiplier`. A disagreement
between this page and the client is a server bug worth chasing.

Recoil and bloom are not here because they are not per-item in any way the server sees; they live
in [Weapon Templates](Weapon-Templates.md) and are read client-side.

NPC weapons are split out on the name prefix the data itself uses. They are the same table and the
same resolution; they simply are not obtainable.
