Last run settled one thing: the game ignores numbers the server sends for a single item. Both rifles read damage 8 however the server described them, even after a full redraw.

This run tries the other route: modules. A module is an upgrade part fitted into a weapon, and each one adds to a stat. The game's own code works out a weapon's stats from its modules itself, and each item can carry "hidden" modules the player never sees. If crafting quality could choose a hidden module, a better batch would build a better rifle. The game's data even has a ladder of damage modules, from +10 to +44.

Two questions, one part each. Part M1 is all inside the game's interface code and changes nothing. Part M2 has the server fit a module to your rifles; like last time, it's on the wire only and isn't saved.

Start the server on the new build first: ~/Games/PIN/start-pin.sh. Restart the game client too, so it loads the updated /invprobe.
