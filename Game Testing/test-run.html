The current test run. This page is rewritten for every run; earlier runs are in git history. Setup, admin commands and the monster type id table: Session Setup.

Last run: area objects are drawn now (blasts, fire patches, spore mines, poison clouds), and area abilities stop at walls.

Crafting is back, with the goal you chose: refining returns, and the quality of what you mine carries through to what you craft. The plan is in Docs/streams/graded-crafting.md. This run has two parts that don't depend on each other.

Part 1 (GRADE1-A to C): can the game show a material's quality, and hold two batches of one material? In the original game every mined batch had a quality from 0 to 1000 and five stats, such as Conductivity or Toughness, packed into one short text sent with the stack. The server has always sent that text empty. The new batch command sends Aluminum stacks with it filled in. These stacks are for looking only: the server doesn't record them, and dbg_inventory resend clears them.

Part 2 (RIFLE-1 to 4): mine metal, craft a Burst Rifle, equip it, log out and back in. This finishes the August run, which crafted a part nothing could equip. The rifle is three recipes: 50 metal makes a receiver, 75 metal makes a barrel, and both parts plus 200 Crystite make the rifle. Nothing is created with createitem.

Start the server on the new build first: ~/Games/PIN/start-pin.sh
