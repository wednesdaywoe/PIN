Tests commit 042b218. Creeping Death and Poison Trail leave a cloud — a "tiny object" — that the server never made, because the step that creates it shipped with no settings. The cloud's own behaviour did ship, as a status effect on the tiny object, so the server now creates the object and runs that effect:

  • Creeping Death (tiny object 387): a cloud where the shot lands that grows from 2 m to about 6 m over its 4 seconds, hitting each enemy inside for the module's damage about once a second.
  • Poison Trail (tiny object 386): ten clouds 2 m apart along the shot's path, each lasting 6 seconds, hitting enemies inside twice a second and slowing them for 5 seconds.

Run on a Biotech frame such as the Recluse. The modules below were picked for readable numbers: Creeping Death 86064 does 120 a hit, Poison Trail 86058 does 20.
