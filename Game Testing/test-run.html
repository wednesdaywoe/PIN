Last run (commit 6ef97ae) both poison clouds worked: Creeping Death's cloud grew and hurt, and Poison Trail module 86058 laid its clouds and set its cooldown. But that module is the version that fires a shot and leaves clouds where it lands, not the Poison Trail you remember.

The game data has both. About 100 modules, including 102707, run the original: for 6 seconds you drop a poison cloud at your feet as you move, and the cooldown starts when the 6 seconds end. Its "drop a cloud" step shipped with no settings, like the clouds last time. Commit ac569be fills it in with the Poison Trail cloud from last run (2 m wide, 6 seconds, damage and a slow every half second). It also adds one rule of PIN's own: no new cloud within 2 m of one of yours, so standing still doesn't pile up thirty clouds in one spot.

Module 102707 hits harder than 86058: 109 a tick, against 20.
