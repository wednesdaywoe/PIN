Last run (commit ac569be) the original Poison Trail worked: running left a trail of clouds that hurt and slowed. Its cooldown didn't show. The log had three faults, fixed in commit af72715:

  • The cooldown was filed under ability 0 instead of Poison Trail (227), because effects never remembered which ability made them. The client had no button to show it on.
  • It counted from the button press, not from when the trail ended, so it would have run out 6 seconds early.
  • Pressing again mid-trail was accepted every time. The "not already trailing" check looked at an empty target list instead of at you.
