The current test run. This page is rewritten for every run; earlier runs are in git history. Setup, admin commands and the monster type id table: Session Setup.

Last run finished the ultimate meter and four abilities: Fuel Air Bomb, Assassinate, Gravity Pull and Fungal Bloom all work, and an ultimate's own kills earn no meter.

This run: making lingering area objects visible. Several abilities leave a small object on the ground that does the work: Fuel Air Bomb's blast and fire patch, Fungal Bloom's spore mines and clouds, and the Recluse poison clouds. They hurt, but nothing was drawn, because the game was never told they exist.

Each character has a list of up to 32 such objects it owns, which the game reads to build its own copy and play the object's visuals and sounds. The server never filled that list in. Now it does: an object is added when it appears and removed when it goes.

This list is now sent for every character, monsters included, which is new to the game. VIS-1 checks that nothing broke because of it. Note anything odd too, such as damage numbers appearing twice.

Then: area abilities and walls (WALL-1 to WALL-3). Until now an area ability reached everyone in range, even behind a rock. The game data marks most of them to stop at walls, so now they do: the server checks for world geometry between the centre of the effect and three points up each target's body. A few abilities are marked to ignore walls; Poison Ball is one and is used as the comparison. The VIS-1 restart covers this change too. You'll need a rock or boulder taller than you.
