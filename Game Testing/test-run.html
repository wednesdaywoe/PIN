Last run finished the cone attacks and knockback; every check passed. The knockback landing fix passed too (CONE-5).

This run is stuns and roots. About 1,000 abilities put an effect on a character that forbids things while it lasts: moving, shooting, abilities, melee, or a full knockdown. The server step that does this was empty, so a "stunned" monster carried on walking and shooting. Now the server tracks what each character is forbidden, ends it when the effect ends, and tells clients, which may play the knocked-down animation. A monster that can't move stands still; one that can't shoot holds fire and picks up again afterwards.

One deliberate gap: effects your own abilities put on you are left to your client, which already handles them. Some of them never end on the server yet, so applying them there could leave you stuck.

The tests use applyeffect, which puts an effect on whatever you have targeted, with two effects straight from the game data:

  • 2967: a 3-second knockdown (no moving, shooting or abilities), then half a second getting up.
  • 3475: a 4-second root (no moving, but it can still shoot).

STUN-4[ ]A knocked-down monster is drawn knocked over

The server sent the "knocked down" switch, but the client didn't draw it. Each monster position update also carries a movement state, and until now the server only ever sent "standing" or "running". The list of states includes "Knockdown", so a knocked-down monster now reports that state instead.

  • Pass: it falls or lies down for about 3 seconds, then gets up and chases you.
  • Something odd instead (sliding, a frozen pose, a T-pose, snapping): describe it. It means the client reads the state but this monster has no knockdown animation, or the state needs pairing with something else.
  • No change from last time: the state isn't what the client animates from either.
