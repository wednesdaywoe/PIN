Last run finished leaps and slams: Meteor Strike and Crater both work and can be repeated, and nothing gets stuck after landing. Crater module 86369 has no knockback stat, so it only damages; 88059 knocks back.

This run is the ultimate meter. Until now it was permanently full, so ultimates could be fired any time. Now:

  • It starts empty each session and survives death.
  • It fills while you're in combat (you hit something, or got hit, in the last 10 seconds): about 2 minutes from empty to full.
  • Dealing damage adds a bonus: a whole monster's worth of health dealt adds 10% of the meter, at most 5% from one hit.
  • The ultimate module's Charge Speed (1 to 1.2) multiplies both.
  • An ultimate needs a full meter and empties it.

The rates are a first guess and easy to change. supercharge on its own shows the meter; supercharge 100 fills it. Every default loadout's ultimate uses the meter, so whichever frame you wear will do.

  • Note how the speed feels. The rate is easy to change.
