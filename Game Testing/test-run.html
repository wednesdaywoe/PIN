Tests commit 6ef97ae, a second try at the poison clouds. The first run (commit 042b218) failed both abilities, for two separate reasons, both now fixed:

  • Creeping Death's cloud touched nothing. The cloud works out its size each tick from a number it saves when it appears and adds one to every tick. The three steps that save and recall that number were never built, so its search radius came out at half a metre and found no one. They now work the way the client's own code does, so the cloud starts 2 m wide and grows half a metre every half second, to about 6 m.
  • Poison Trail read 0 for every stat. Equipping a module in game never recalculated the character's stat totals, which is where abilities read their numbers. So the clouds lasted 0 seconds (created and removed at once), the cooldown was 0, and the range was 0. Equipping now recalculates them.

What each cloud should do, from the shipped data:

  • Creeping Death (module 86064): a cloud where the shot lands, lasting 4 seconds. Every half second it poisons each enemy inside for 120.
  • Poison Trail (module 86058): small clouds 2 m wide, laid along the shot's path, each lasting 6 seconds. Every half second each one hits enemies inside for 20 and slows them for 5 seconds. A 15-second cooldown.
