Last run: a crafted item can carry its own numbers. The server builds a hidden module into it, and the game shows the better stats (the rifle went from 8 damage to 12).

This run: the server now keeps each batch of a material separate. Until now it kept one pile per material, so two batches of Iron Bars at different qualities would have merged. Now each batch keeps its own quality and count, is saved, and is spent in a set order: material with no quality first, then the worst batch first, so the best is kept. This is the base the rest of graded crafting builds on.

Unlike the last few runs, these batches are real: they're saved, and crafting can spend them.
