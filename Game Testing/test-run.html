The current test run. This page is rewritten for every run; earlier runs are in git history and in the older pages linked from the index. Setup, admin commands and the monster type id table: Session Setup.

Tests commit 205266b, after a report that area abilities only did impact damage. Poison Ball, the chemical grenade and most other fired area abilities keep their area effect in the ammo's impact ability, which the server never ran — the shot only dealt its own direct damage. Now it runs where the shot lands, the area search centres there, the poison damages what it poisoned, and the poison's duration ends instead of lasting for ever.

Not fixed, don't test: Creeping Death (34734) and Poison Trail (40592). Their cloud is a server-only step whose settings never shipped, so the server has nothing to build it from. That needs a design decision, not a fix.

Every entry uses Poison Ball, module 77108 (ability 34943), on a Biotech frame such as the Recluse. The ability reads its radius, damage and duration off the equipped module, so it must be slotted, not run with the admin ability command.

Recheck: npc 1196 three times without moving, then one shot at them.

AREA-2[x]The poison ends

Read off the same run as AREA-1. The duration step was rebuilt from a guess, so this is the entry that checks the guess.

Pass: one per poisoned Fiend, each reading 8 to 10 seconds with the same register value, and no damage lines for them after it. A reading of exactly 10 with a register of 0 or NaN means the fallback was used — record it; the poison ended, but not for the data's reason.

Passed 2026-10-03. Six poisons, each ended its effect after 8 s (register 8): the module's own duration stat, not the fallback, and no damage after it.
