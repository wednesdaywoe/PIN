Last run finished stuns and roots; every check passed. The knockdown animation plays, roughly (recorded as CLIENT-5 and left for now).

This run is abilities you throw and then press again to set off in mid-air: Poison Ball's two-press version, Shield Wall, Electrical Storm and a few others. The server used to treat anything an ability fired as landing the instant it was thrown, so there was never anything in the air to set off. Now a thrown thing flies: the server works out its arc (including the drop) and holds the landing until the flight time has passed. A second press inside that time bursts it where it is.

Every entry uses Poison Ball, because its mid-air burst makes the same poison cloud as its landing. Shield Wall's burst would make a wall, and the server can't spawn that wall yet.

One thing from the game data: the second press has to come within half a second of the throw. After that, pressing again throws a new ball instead. A ball travels about 40 m in that half second.

Two Poison Ball modules are used:

  • 86057: the throw-then-trigger version (ability 41865).
  • 77108: the plain one-press version used in the last poison tests (ability 34943). It doesn't have a second press, but its throw now takes time to land too, so it's the check that nothing broke.

DET-5[ ]While a ball is flying, pressing again detonates it instead of throwing another

The ability picks "throw" or "detonate" by checking for a short mark the throw puts on you, which the data ends after half a second. The server now keeps that mark on you for as long as your ball is in the air. So any press during the flight detonates, and the 13-second cooldown starts at the burst. The unknown is your game client: it also guesses what a press does, and may draw a new throw while the server detonates.
